# 参考图与输出的视觉验收

同时查看源图和每张输出；必要时裁切放大商品与字幕。逐项记录 pass / fail / uncertain，并引用可见事实。不要根据图片是否保存或模型的自述判定通过。

记录目标重构深度（1～10）和用户锁定项。按档位计划判断实际变化：低档位不要求大幅换场景；高档位若仅改色或裁切需指出未充分实现。不要给图片编造精确实测深度或平台查重分数。商品保真标准不会因深度增高而放宽。

| 项目 | 如何判断 |
|---|---|
| 主商品 | 款式、数量、外观、相对比例、完整性；没有增减、融合或改成相近款 |
| 关键结构 | 依实际产品检查挂孔、接口、扣具、包装、标签、图案等；未在参考图确认的细节不能编造 |
| 配件 | 按生成前清单逐个数；工具、包装内物件与新场景道具分别判断，不把道具误当套装组成 |
| 文案 | 逐字对照原文、表情符号（emoji）和商品标签；OCR 辅助定位，视觉确认可读性和实际内容 |
| 人物样貌 | 如适用，对照已计划的外貌变化及身份锁定项；检查面孔、发型、神态、人物数量、解剖与商品比例。商品印花/角色脸不能被改；只有手部或无人时不得强加可见人脸。无人则记不适用，不为该项补人。 |
| 人物表情 | 对照原表情与计划目标，检查视线、眉眼、嘴部及情绪时刻是否按目标深度产生适当变化，是否自然并符合互动，并确认原图情绪基调保留；未有用户明确要求时，笑转哭、悲伤或愤怒等情绪方向改变记为不通过，不能用高深度解释。保留身份不等于冻结表情。用户锁定表情优先，商品角色表情和广告emoji保持。无可见人脸记不适用，不凭空补脸。 |
| 场景重构 | 指出具体改变：环境、机位、摆放、光线、人物动作；不虚构平台检测分数 |
| 画面合理性 | 手部、接触、透视、阴影、反射、材质和文字是否自然 |
| 界面清理 | 仅对指定轮播点、按钮等界面检查；广告字幕与产品标签不一并删除 |

交付至少说明：每张参考生成几张、总计几张、路径、生成状态、视觉状态和问题。只有全部适用项通过才称视觉合格；unknown/uncertain 不等于通过。用户明确不要视觉检查时记录 `visual_review: skipped_by_user`，不要私自跑评分或修图。

报告可用 JSON：

```json
{
  "source": "absolute/source.png",
  "output": "absolute/result.png",
  "generation_status": "completed",
  "visual_review": "reviewed",
  "checks": {"product_identity": "pass", "accessory_counts": "fail", "copy": "uncertain", "scene_redesign": "pass"},
  "issues": ["Describe observed differences"],
  "visual_pass": false,
  "platform_duplicate_check_tested": false
}
```
